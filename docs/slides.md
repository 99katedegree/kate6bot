# 🎮 kate6bot

### Discordサーバーを「ちょうどいい相手と遊べる場所」にしてくれるお世話係

非エンジニア向けガイド

---

## このbotは何をしてくれる?

平日(月〜金)の毎日、**自動で「一緒に遊ぶ人」を選んで、集合場所まで用意してくれます。**

| やること | botが代わりにやってくれること |
| --- | --- |
| 🎲 遊ぶ相手を決める | くじ引きで公平に選出 |
| 🏷️ 実力が近い人と組む | 「段位」をもとに候補を絞る |
| 🔊 集合場所を用意 | 専用のボイスチャンネルを作る |
| 🙋 初対面でも安心 | 自己紹介を自動で紹介 |
| 🧹 後片付け | 終わったら全部きれいに戻す |
| 💬 気軽に発言 | botへのDMが、名前なしで匿名掲示板に載る |

人が手作業でやると大変なことを、**全部おまかせ**できます。

---

## 1週間の流れ(ひと目で)

```
 木曜 20:00           月〜金 0:00         月〜金 22:15      月〜金 22:30
    │                    │                  │                │
 📣 来週の              🎲 その日の          ⚠️ 終了         🧹 おしまい
 段位の確認              メンバー発表        15分前の警告    自動で片付け
```

> 月曜〜金曜は、**毎日あたらしいメンバー**で遊べます。

---

## ① 木曜の夜:「段位、変わりましたか?」

- 木曜 20:00 に、みんなが見るチャンネルへ**翌週に向けた**お知らせが届きます
- ボタンを押すだけで、**自分にしか見えない画面**が開きます
  - **「段位を設定する」** → 一覧から選ぶだけ
  - **「今週は参加しない」** → 来週(月〜金)は、毎日のくじ引きの対象から外れる
- 忙しい週は、気軽にお休みできます 🙆

> 💡 `/段位` と入力しても、いつでも段位を変えられます

---

## ② 月〜金の 0:00:その日のメンバーが決まる 🎲

- 同じくらいの段位の人の中から、**くじ引きで自動選出**
- 選ばれた人には専用の「pickupロール」が付き、**選ばれた人だけが見える部屋**が現れます
- みんなが見るチャンネルに発表が出ます

> 📣 「今日は ○○さん と △△さん □□さん ✕✕さん をピックアップしました！」

---

## くじ引きは「公平」になるように作られています

- **まだ選ばれていない人ほど当たりやすい**
  → 毎回同じ人ばかり選ばれることがありません
- **これまで一緒になっていない人同士ほど組まれやすい**
  → いろんな人と遊べます
- 「参加しない」にした人は、その週(月〜金)は対象外
- 候補が足りない日は「今日は不成立でした」と**正直にお知らせ**

> 当たりにくくなることはあっても、**ゼロにはなりません**。全員にチャンスがあります。

---

## 「段位」ってなに?

実力やレベル感が近い人同士で遊べるようにするための**目安**です。

`1段` `2段` `3段` `4段` `5段` `6段` `勇士` `最高峰`

- 自分と**同じ段位**か、**ひとつ下の段位**の人が候補になります
- ひとり1つだけ。ロール(肩書き)としてサーバー上でも見えます
- 管理者がロールを直接変えても、botが自動で追従します

> 🔰 **「勇士」「最高峰」** は2人パーティの制限があるため、その週は**1人だけ**選ばれます

---

## ③ 自己紹介チャンネル:初対面でも話しかけやすく 🙋

- サーバーに入ると、**あなた専用の自己紹介チャンネル**が自動で作られます(他の人には見えません)
- あわせて、**あなた専用のウェルカム用チャンネル**も作られ、そこに案内が届きます
- 案内と一緒に、**段位を選ぶメニュー**も出ます(選ぶだけでロールが付きます。段位の選択と自己紹介の投稿が済んだら、ウェルカム用チャンネルは自動で消えます)
- 好きに自己紹介を書いてOK
  - 投稿し直すと、**古い投稿は自動で消えて最新だけ**が使われます
- **選ばれた日だけ**、同じグループの人に自己紹介が共有されます
  - 普段は他の人には見えません

---

## ④ 平日の夜:遊びの時間 🔊

- 選ばれた人だけが入れる**専用のテキストチャンネルとボイスチャンネル**が作られます
  - 集合・通話は**ボイスチャンネル**、連絡は**テキストチャンネル**
- 選出された人の自己紹介が、**テキストチャンネル**に自動で貼られます
- 時間はあくまで目安。**前後してOK** です

| 時刻 | botのお知らせ |
| --- | --- |
| 22:15 | 「あと15分で終了します」 |
| 22:30 | 「お疲れ様でした！」→ 自動で終了 |

---

## ⑤ 22:30:自動で後片付け 🧹

誰も手を動かさなくても、**毎日きれいにリセット**されます。

1. ボイスチャンネルに残っている人を退出させる
2. pickupロールを外す
3. 専用のテキストチャンネルとボイスチャンネルを作り直して、次の日に備える

> 部屋に居残ったり、前の週のメンバーが見え続けたりしません。

---

## ⑥ 匿名掲示板:名前を出さずに発言できる 💬

- botに**DMでメッセージを送る**と、**名前を出さずに**「匿名掲示板」チャンネルに載ります
- 掲示板は**みんなが見られて、リアクションもできます**(書き込めるのはbot経由だけ)
- 文字と**画像**(1回に4枚まで、1枚8MBまで)に対応しています。動画やファイルは、まだ投稿できません
- botからの返信は、ありません(送った内容が、掲示板に載るだけです)
- **編集**: DMで送ったメッセージを編集すると、掲示板の投稿も書き換わります(文字のみ。編集できるのはDMからだけです)
- **削除**: DMのメッセージを削除するか、掲示板で直接削除すると、投稿が消えます

---

## 裏側でこっそり働いていること 🛠️

- 🔍 **毎日 3:00(と、botの起動時)** … サーバーのメンバーと自己紹介チャンネルを突き合わせて、ズレを自動で修復
  - 新しく入った人のチャンネルが無ければ作る / 消えていたら作り直す
  - 抜けた人のチャンネルが残っていれば削除する
- 📝 **毎日 3:00** … 自己紹介チャンネルの名前を、最新のDiscord名に合わせる
- 🔒 **毎日 3:00(と、botの起動時)** … 見せるべきチャンネル / 隠すべきチャンネルの権限をチェックして整える
- 🔊 **毎日 3:00(と、botの起動時)** … pickupのテキストチャンネルとボイスチャンネルが揃っているか確認して、無ければ作る
- 👋 **毎日 3:00(と、botの起動時)** … 段位の設定か自己紹介の投稿がまだの人に、ウェルカム用チャンネルが無ければ作って案内する(済んだ人の分は片付ける)
- 📒 **すべての動き** … 管理者向けのログ用チャンネルに記録される(一般メンバーには非表示)

> 投稿した自己紹介は、一緒に遊ぶときに自動で共有されます。何度でも投稿し直せて、使われるのは最新の1件だけです。

## よくある質問

**Q. 選ばれたのに都合が悪い…**
A. 参加は強制ではありません。前の週の木曜までに「今週は参加しない」を押してください。

**Q. 自分の自己紹介は誰に見られる?**
A. 普段は他の人から見えません。選ばれた日の、同じグループの人にだけ共有されます。

**Q. 段位を間違えて設定した！**
A. `/段位` でいつでも直せます。

**Q. 毎回同じ人と組まれない?**
A. 組まれにくくなるように作られています。
